# HPC-DAT website

Static GitHub Pages site for <https://hpc-dat.github.io/>.

News cards in `index.html` are generated from the `News` category in
[`HPC-DAT/forum`](https://github.com/HPC-DAT/forum). Edit News in the forum, not
between the `news-sync` markers in this repository.

The site has no runtime dependencies or build step. Open `index.html` locally to
preview it.
